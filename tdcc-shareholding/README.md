## 欄位

`資料日期`、`證券代號`、`證券名稱`、`市場別`、`類別`、`序`、`持股分級`、`人數`、`股數`、`占集保庫存數比例%`

- 日期為西元 YYYYMMDD。
- 「差異數調整」那一列的人數是空值。
- 若某檔某週沒有差異數調整，該週是 16 列而不是 17 列。

讀取範例：

```python
import pandas as pd
df = pd.read_parquet("tdcc_shareholding_1y.parquet")
```
